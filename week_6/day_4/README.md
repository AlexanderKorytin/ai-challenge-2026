# День 29. Оптимизация местной модели: хозяин таверны «Песнь эльфа»

Стадия: `Validation`.

## Постановка

Условие дня: оптимизировать местную модель под свою задачу. Настроить параметры (температура,
предел длины ответа, окно контекста), попробовать квантование, изменить шаблон запроса. Сравнить
качество до и после, скорость и расход ресурсов.

Задача модели — ведущий настольной игры Betrayal at Baldur's Gate. Роль — хозяин таверны
«Песнь эльфа»: с этой плитки начинается партия. Игрок называет ход по-русски. Хозяин отвечает
тремя разделами: «Правило» по книге правил со ссылкой, «Сцена», «Что дальше» — придуманное
развитие событий.

Дизайн и план лежат в ветке `main`: `docs/оптимизация-местной-модели.md`,
`docs/план-оптимизация-местной-модели.md`.

## Итог

Модель — `qwen3.5:9b-q4_K_M` в Ollama на Маке M3 Pro 18 ГБ. Замер — 15 реплик игрока и партия
из 8 ходов. Подробности, все наборы настроек и оговорки — `сравнение.md`.

| Мера | До | После |
|---|---|---|
| правило верно | 6 из 12 | 7 из 12 |
| ответа нет вовсе | 5 из 15 | 0 из 15 |
| три раздела в ответе | 0 из 15 | 15 из 15 |
| ссылка на нужный раздел книги | 0 из 12 | 10 из 12 |
| новое обстоятельство в сюжете | 2 из 15 | 15 из 15 |
| выбор для игрока | 5 из 15 | 15 из 15 |
| партия из 8 ходов | встала на 2-м ходу | 8 ходов из 8 |
| время ответа, медиана | 109,9 с | 18,3 с |
| окно | 4096 | 8192 |

Что изменено:

- шаблон запроса — `инструкции/хозяин.md`: роль, три раздела, ссылка на книгу, два примера;
- рассуждения выключены: верных решений они не прибавляли, а ответ с ними шёл 2–4,5 минуты;
- температура 1,0: пробы 0 и 0,7 дали меньше верных решений;
- предел длины ответа 400 токенов: самый длинный ответ — 358;
- окно 8192: самый длинный запрос партии — 4281 токен.
- квантование: сборка `q8_0` качества не прибавила, занимает 9,2 ГБ против 5,8 ГБ и отвечает за
  24,3 с против 18,3 с — оставлена `q4_K_M`.

Чего оптимизация не дала: верность решения по правилу осталась около 60 %, отказ на вопрос вне
книги — 1 из 3, вымысел чаще попадает в раздел «Правило» (6 ответов из 15 против 2).

## Как запустить

1. Собрать индекс книги правил. Текст правил защищён авторским правом и в репозиторий не входит:
   программа скачивает PDF с сайта издателя, сверяет отпечаток и переводит текст в Markdown.

   ```
   uv run --with pymupdf правила.py
   ```

2. Собрать модель.

   ```
   ollama create tavern-keeper -f Modelfile
   ```

3. Запустить `myharness` из папки `test/` с профилем «хозяин-таверны» и выбрать модель командой
   `/model ollama/tavern-keeper`.

   ```
   cd test && MYHARNESS_PROFILES=../profiles uv run --project ~/challenge/main/myharness myharness --profile хозяин-таверны
   ```
