# День 26. Местная языковая модель

**Стадия: Validation** — 2026-10-05, ждёт подтверждения пользователя (ход стадий —
`docs/состояние-местная-модель.md` в `main`).

## Постановка

Запустить местную языковую модель (Ollama, LM Studio, llama.cpp и подобные). Проверить: модель
запускается на своей машине, к ней можно обратиться через командную строку или HTTP API, она
отвечает на простой запрос. Сделать минимум три запроса разной сложности.

## Что это

Местная модель работает в службе Ollama на этом Маке (Apple M3 Pro, 18 ГБ). К ней обращается
`myharness` по HTTP API службы — `http://127.0.0.1:11434/v1`, тот же формат, что у DeepSeek.
Условие говорит «командная строка или HTTP API»; выбран один путь — `myharness`.

| пункт условия | чем закрыт |
|---|---|
| модель запускается на своей машине | Ollama 0.34.4, модель `qwen9-day26`: 7,3 ГБ, целиком на видеоядре (`ollama ps`: «100% GPU») |
| обращение через HTTP API | `myharness` шлёт запросы службе; имя модели `ollama/qwen9-day26` |
| модель отвечает на простой запрос | «Столица Австралии?» — «Канберра» за 13,8 с |
| три запроса разной сложности | наряд `test/наряд.json`: факт, рассуждение, код |

Правка общего инструмента (в `main`, дизайн `docs/местная-модель.md`, план
`docs/план-местная-модель.md`):

- поставщика называет имя модели: `ollama/<имя>` уходит в Ollama, прочие имена — в DeepSeek;
- `/model` показывает модели обоих поставщиков, местные — с пометкой «местная»;
- окно местной модели называет Ollama, от него считаются полоска занятости и порог сжатия;
- цена местной модели — 0;
- ключ DeepSeek в Ollama не уходит;
- архивариус, судья и распознаватель остаются на DeepSeek.

## Модель

`qwen3.5:9b-q4_K_M` — Qwen 3.5 на 9 млрд параметров в 4-битном сжатии, 6,6 ГБ на диске.

Прежняя `Qwen3.8-27B` в сжатии `IQ3_XXS` отставлена: 11 ГБ весов оставляют на окно 4096
токенов, скорость около 8 токенов/с (замер 2026-09-29).

Окно задаёт `Modelfile` строкой `PARAMETER num_ctx`. Размер выбран замером на коротком запросе:

| окно, токенов | память модели | где считает | токенов/с |
|---|---|---|---|
| 8 192 | 6,4 ГБ | 100% GPU | 23,3 |
| 16 384 | 6,7 ГБ | 100% GPU | 23,3 |
| 32 768 | 7,3 ГБ | 100% GPU | 23,2 |
| 65 536 | 8,5 ГБ | 100% GPU | 23,3 |

Взято 32 768 — наибольшее из согласованного в плане списка. Скорость при заполненном окне не
мерилась.

## Три запроса

Прогон `./запуск.sh --batch наряд.json`, 2026-10-05. Рассуждения модели включены. Числа — из
`test/myharness-journal.jsonl`, расход называет сама служба.

| запрос | время | вход | выход | токенов/с | итог |
|---|---|---|---|---|---|
| факт: столица Австралии, одним словом | 13,8 с | 60 | 268 | 19,5 | верно: «Канберра» |
| рассуждение: три человека и три животных | 59,0 с | 105 | 1337 | 22,7 | верно: Аня — собака, Боря — попугай, Вера — кошка; четыре шага |
| код: `merge_intervals` на Python | 11,0 с | 119 | 240 | 21,8 | слияние верно, одно условие нарушено |

Время первого запроса включает загрузку модели в память.

Третий ответ проверен запуском. Четыре проверки слияния проходят: несортированный вход,
соприкасающиеся отрезки, вложенный отрезок, пустой список. Пятая падает: условие «входной список
не меняй» нарушено — функция сортирует вход на месте (`intervals.sort`). Модель ответила за 11 с
почти без рассуждений и условие пропустила.

Выход много больше ответа: в него входят рассуждения. На слово «Канберра» ушло 268 токенов.

## Что видно

- Местная модель на этом Маке отвечает со скоростью 20–23 токена/с. Простой вопрос с
  рассуждениями занимает около 10 с.
- Факт и логическую задачу в три шага модель решила верно. В задаче на код она дала рабочий
  алгоритм и нарушила одно явное условие.
- Оценка веса запроса до отправки для местной модели грубая: `myharness` предсказал 134 токена
  входа, служба насчитала 60. Счёт идёт словарём DeepSeek, экран помечает его как оценку.

## Что не проверялось

- Вызов инструментов местной моделью (автомат задачи, MCP).
- Качество выжимок сжимателя и JSON извлекателя фактов на местной модели.
- Длинный разговор до порога сжатия.
- Сравнение с другими моделями: решение пользователя — в задачу дня не входит.

## Что где лежит

- `Modelfile` — рабочая модель дня: основа и окно;
- `profiles/местная.json`, `profiles/местная.md` — профиль: короткие ответы по-русски;
- `test/наряд.json` — три запроса;
- `test/запуск.sh` — живой разговор из песочницы либо наряд;
- `test/myharness-journal.jsonl` — журнал прогона: вопросы, ответы, рассуждения, расход.

## Как повторить

1. Загрузи основу: `ollama pull qwen3.5:9b-q4_K_M`.
2. Собери модель дня: `ollama create qwen9-day26 -f Modelfile`.
3. Запусти наряд: `cd test && ./запуск.sh --batch наряд.json`.
4. Для живого разговора запусти `./запуск.sh` без доводов.
