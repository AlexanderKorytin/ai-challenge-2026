**Вопрос.** Напиши функцию Python merge_intervals(intervals). Она получает список отрезков [начало, конец] в любом порядке и возвращает отсортированный список, где пересекающиеся и соприкасающиеся отрезки слиты в один. Пустой список даёт пустой список. Входной список не меняй.

**Ответ.**

```python
def merge_intervals(intervals):
    if not intervals:
        return []
    
    intervals.sort()
    merged = [intervals[0]]
    
    for start, end in intervals[1:]:
        prev_start, prev_end = merged[-1]
        
        if start <= prev_end:
            merged[-1] = (prev_start, max(prev_end, end))
        else:
            merged.append((start, end))
    
    return merged
```
