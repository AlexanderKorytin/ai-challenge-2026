# Игровой агент

Личный агент подбора игр в Steam. Он узнаёт ваш вкус по библиотеке и короткому разговору. Каждый
день он предлагает 10 игр, каждую неделю отмечает будущие выпуски в календаре и сообщает о скидках.
Работает на вашем Маке, в браузере на `http://127.0.0.1:8791`, значок 🎮 — в строке меню.

## Что нужно

- Мак от 16 ГБ памяти: местная модель `qwen3.5:9b` занимает 7,3 ГБ на видеоядре.
- [Ollama](https://ollama.com/download) — служба местных моделей. Модели агент скачает сам.
- [`uv`](https://docs.astral.sh/uv/) — менеджер окружений Python:
  `curl -LsSf https://astral.sh/uv/install.sh | sh`.
- `git`.
- Учётная запись Steam. Ключ Steam Web API вы заведёте в мастере, инструкция там же.
- По желанию — ключ DeepSeek. Без него агент работает только на местной модели: опрос медленнее и
  хуже. Ключ IsThereAnyDeal тоже по желанию: он даёт исторический минимум цены в уведомлении.

## Установка

1. Склонируйте репозиторий.
2. В Терминале выполните `agents/games/deploy/установить.sh приложение`.
3. Откройте `~/Applications/Игровой агент.app`.
4. Пройдите мастер в браузере: вход через Steam, ключи, местная модель, знакомство.

После знакомства агент сам ставит себя в автозапуск: веб, значок, задания недели и дня. Первое
задание дня запускается сразу. Снять всё — `agents/games/deploy/установить.sh снять`.

## Где что лежит

| Что | Где |
|---|---|
| ключи (права 600) | `~/.config/games-agent/config.json` |
| хранилище, вкус, разговор, RAG, журнал | `~/.local/share/games-agent/` |
| журналы служб | `~/Library/Logs/games-agent/` |
| календарь для подписки | `http://127.0.0.1:8791/calendar.ics` |

Пароль Steam агент не видит: вход идёт на странице Steam. Агент только читает вашу библиотеку и
список желаемого. Писать в настоящий список желаемого Steam он не может, и это нарочно. Свой
список желаемого он ведёт сам.

## Устройство

- `mcp_servers/steam` — магазин Steam, хранилище SQLite, вход, ключи и сервер MCP для модели.
- `agents/games` — вкус в карточке `myharness`, отбор местной моделью, RAG по вашей истории,
  задания, советник, веб, значок и установщик.

Замысел и решения описаны в `docs/игровой-агент.md`.
