# config Specification

## Purpose
Хранение настроек harness между запусками: ключ DeepSeek API, выбранная модель и имя активного
профиля. Здесь лежит единственный секрет приложения, поэтому у файла отдельные правила доступа
и отдельная точка переопределения для проверок.

## Requirements

### Requirement: Каталог настроек переопределяется переменной окружения
Инструмент SHALL брать каталог настроек из `$MYHARNESS_CONFIG_DIR`, а при незаданной переменной —
из `~/.config/myharness`.

Требование не косметическое: проверки, писавшие в настоящий каталог, однажды затёрли рабочий ключ
пользователя. Всё, что пишет в домашний каталог, обязано иметь переопределение пути.

#### Scenario: проверки уводят настройки во временный каталог
- **WHEN** задана переменная `MYHARNESS_CONFIG_DIR`
- **THEN** чтение и запись настроек идут только внутри указанного каталога
- **AND** файл в `~/.config/myharness` не создаётся и не изменяется

#### Scenario: обычный запуск
- **WHEN** переменная не задана
- **THEN** настройки читаются из `~/.config/myharness/config.json`

### Requirement: Файл настроек защищён правами доступа
Инструмент SHALL выставлять файлу настроек права `600` при каждой записи и SHALL создавать
недостающие родительские каталоги.

#### Scenario: первая запись ключа
- **WHEN** пользователь проходит авторизацию, а каталога настроек ещё нет
- **THEN** каталог создаётся, файл записывается, права файла — `600`

### Requirement: Испорченный файл настроек не роняет запуск
Инструмент SHALL возвращать настройки по умолчанию, если файл отсутствует, нечитаем или содержит
неразбираемый JSON.

Молчаливый откат к умолчаниям здесь допустим: без ключа harness всё равно предложит `/auth`,
а падение на старте не оставляет пользователю выхода.

#### Scenario: файл повреждён
- **WHEN** `config.json` содержит неразбираемый JSON
- **THEN** harness запускается с умолчаниями: ключ отсутствует, модель `deepseek-v4-flash`,
  профиль `default`

### Requirement: Секрет не покидает файл настроек
Инструмент SHALL хранить ключ API только в файле настроек и SHALL NOT записывать его в журнал
прогонов, в профили и в вывод на экран.

#### Scenario: запись прогона
- **WHEN** ответ модели получен и записывается в журнал
- **THEN** в записи журнала нет ключа API ни в каком виде
