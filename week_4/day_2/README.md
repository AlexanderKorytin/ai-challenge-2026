# День 17. Первый инструмент MCP

**Стадия: Executing → Spec (второй рубеж).**
Код — в `main`: сервер `mcp_servers/cbr/`, мост в `myharness`. Здесь постановка, песочница и
видеоотчёт.

## Условие

Реализовать свой MCP-сервер вокруг любого API: регистрация инструмента, описание входных
параметров, возврат результата. Подключить инструмент к своему агенту, вызвать его из
приложения, получить и использовать результат. Итог — агент вызывает MCP-инструмент и получает
результат.

## Видение пользователя

git и GitHub уже подключены в дне 16 — взять другой API. Сервер положить на наш VPS.

## Что решили

Дизайн — `docs/свой-mcp.md` в `main`, план — `docs/план-свой-mcp.md`, ход и вердикты —
`docs/состояние-свой-mcp.md`, требования — `openspec/specs/mcp/`.

- **API — официальные курсы валют ЦБ РФ** (`www.cbr.ru/scripts/`, XML без ключа). Результат
  легко сверить глазами на сайте ЦБ.
- **Сервер свой**, отдельной программой: `mcp_servers/cbr/server.py`, каркас `MCPServer` из
  библиотеки `mcp` 2.2.
  - *регистрация инструмента* — декоратор `@srv.tool()`;
  - *описание входных параметров* — подпись функции, `Annotated[str, Field(description=…)]`,
    библиотека строит из неё JSON Schema;
  - *возврат результата* — модель данных (`Rate`, `Dynamics`): клиент получает и текст, и
    `structuredContent` со схемой выхода.
  - Инструменты: `get_rate(currency, date?)` и `get_rate_dynamics(currency, date_from, date_to)`.
    В ответе всегда `rate_date` — дата, на которую ЦБ установил курс: на выходной ЦБ отдаёт курс
    пятницы, а на ещё не наступившую дату — ошибку «курс ещё не установлен» с последним курсом.
- **Сервер на VPS** `83.136.235.149`: служба systemd не от root, слушает только `127.0.0.1`,
  наружу — nginx по HTTPS, доступ по токену `Authorization: Bearer …`. Адрес
  `https://83.136.235.149:8443/mcp` — сертификат Let's Encrypt на сам IP: на имя
  `koritin84.fvds.ru` выпуск упёрся в общий недельный предел хостинга.
- **Мост в агенте** (`myharness/src/myharness/mcp_tools.py`): модель видит только инструменты,
  разрешённые правилами `permissions.allow` в `.claude/settings.json` — тот же файл и вид
  правил, что у Claude Code. Инструменты MCP идут в тот же круг вызовов, что инструменты автомата
  задачи (день 13): модель зовёт → программа отдаёт вызов серверу → результат уходит модели →
  модель отвечает. Соединение живёт весь сеанс.

## Как запустить

```
cd week_4/day_2/test
export CBR_MCP_TOKEN=$(ssh challenge "grep ^CBR_MCP_TOKEN= /opt/challenge/.env | cut -d= -f2")
uv run --project ~/challenge/main/myharness python живой_обмен.py "Сколько рублей стоили 1500 долларов 1 сентября и сколько сегодня?"
myharness          # то же в терминале; /mcp покажет инструменты с пометкой «✓ модели»
```

Токен на Маке не хранится — берётся с сервера при запуске.
