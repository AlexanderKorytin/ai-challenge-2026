# Правила проекта

1. У каждой открытой функции (имя без `_` в начале) есть строка документации.
2. Печатает на экран только `tasks/cli.py`. Прочие модули возвращают значения или поднимают исключения.
3. Путь к файлу задач знает только `tasks/storage.py` (функция `tasks_path`). Прочие модули его не повторяют.
4. Голый `except:` запрещён: ловить только названные исключения.
