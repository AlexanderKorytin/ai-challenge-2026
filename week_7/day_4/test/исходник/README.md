# Учёт задач

Маленькая программа командной строки: список дел в файле JSON.

## Запуск

```bash
python -m tasks.cli add купить хлеб
python -m tasks.cli list
python -m tasks.cli report
```

Файл задач — `tasks.json` в текущем каталоге либо путь из переменной `TASKS_FILE`.

## Команды

| Команда | Что делает |
|---|---|
| `add <текст>` | добавляет задачу |
| `list` | печатает все задачи |
| `report` | печатает сводку |
