## 1. Тикет T-1001. Почему не работает авторизация?

Время: 51 с. Вызовы: `mcp__support__get_ticket`, `mcp__support__find_user`, `mcp__rag__search` — «авторизация ошибка ключ не принят DeepSeek API проверка правильности»

```
В тикете ошибка: «ключ не принят DeepSeek API (проверьте правильность)». Это значит, что DeepSeek отклонил ваш ключ: он либо отозван, либо скопирован с ошибкой. Сеть при этом работает (при её сбое myharness пишет «не удалось проверить ключ», а не об ошибке ключа).

Шаги решения:
1. Откройте кабинет DeepSeek и убедитесь, что ваш API-ключ не отозван.
2. Скопируйте ключ заново, без пробелов в начале и конце строки.
3. Введите команду `/auth` в myharness (она работает даже после того, как меню скрыто) и вставьте исправленный ключ.
4. После сообщения «авторизация сохранена» ключ вводить повторно не нужно.

Источники: week_7 › day_3 › FAQ.md
```

## 2. Тикет T-1002. Почему не работает авторизация?

Время: 17 с. Вызовы: `mcp__support__get_ticket`, `mcp__support__find_user`

```
Причина: у пользователя OLLAMA_HOST и OLLAMA_API_KEY не заданы, поэтому связь с локальным сервером Ollama невозможна (ошибка в тикете: «Ollama не отвечает»). Служба Ollama на `http://127.0.0.1:11434` не работает или отсутствует.

Шаги решения:
1. Проверьте наличие локальной службы Ollama. Если её нет — установите через https://ollama.com/.
2. Запустите службу Ollama:
   - **macOS**: `brew install ollama && ollama serve`
3. Если служба работает, убедитесь, что порт 11434 доступен и нет блокировок фаервола.
4. После запуска проверьте работу через http://127.0.0.1:11434/api/tags.
5. Если ошибка сохранится — в документации этого нет, обращайтесь к специалисту поддержки.

Источники: T-1002
```

## 3. Я vera@example.com. Почему не работает авторизация?

Время: 11 с. Вызовы: `mcp__support__find_user`

```
Нашла ваш аккаунт. У вас не задана переменная окружения `OLLAMA_API_KEY`, это и требуется для авторизации.

Вот шаги решения:
1. Узнайте API-ключ у поставщика услуг Ollama (через настройки пользователя или через веб-интерфейс ollama.com).
2. В файле конфигурации терминала `myharness` (или в переменной окружения) установите значение: `OLLAMA_API_KEY=ваш_ключ`.
3. Перезапустите терминал `myharness`.

Источники: пользователь U-03
```
