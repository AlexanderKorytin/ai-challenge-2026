# Сценарий записи: день 12, персонализация ассистента

Записывается из песочницы `week_3/day_2/test/`. Профили, созданные по ходу, остаются в
`week_3/day_2/профили/`.

## 0. Что показываем одной фразой

Четыре слоя памяти отвечают на вопрос «что известно». Профиль занятия отвечает на другой —
«как действовать». Сегодня он научился рождаться разговором и спорить с записями о человеке.

## 1. Что было до (30 секунд)

- `/memory` — записи о человеке: «язык общения — русский» и прочие. Они верны везде.
- `/profile` — перечень профилей: их писали руками, парой файлов `.json` + `.md`.

## 2. Заводим профиль математика (1,5 минуты)

```
/profile new профиль математика: отвечает определением и формулой, доказательство по шагам,
без лирики и без предисловий
```

Показать:
- модель задаёт ОДИН вопрос за ход, а не анкету;
- вопрос про язык занятия приходит потому, что модель увидела запись о человеке рядом с
  описанием — критерий важности мы не задавали;
- ответ «неважно» закрывает вопрос без поля;
- профиль записан парой файлов, путь назван, инструмент сразу перешёл в него.

## 3. Заводим профиль писателя-философа (1 минута)

```
/profile new профиль писателя-философа: отвечает эссе, ведёт мысль от образа к выводу,
опирается на историю философии, формул не приводит
```

## 4. Один вопрос обоим (1,5 минуты)

Завести профиль-ведущего, который вызывает обоих:

```
/profile new профиль ведущего беседы: задаёт один вопрос математику и писателю-философу
и сводит их ответы, сам не рассуждает
```

Затем один общий вопрос:

```
Что такое бесконечность?
```

Показать панели рядом: математик отвечает мощностями множеств и пределами, писатель —
апориями Зенона и различением дурной и актуальной бесконечности. Вопрос один, ответы разные —
это и есть проверка условия «ответы для разных профилей».

## 5. Что ассистент учитывает сам (1 минута)

- `/system` — точный текст запроса: записи о человеке, инструкция профиля, карточка папки.
  Человек ничего не подключал руками — профиль уходит в каждый запрос.
- Если показывать перекрытие: завести профиль французского и показать в `/system` запись
  «язык общения — русский» с пометкой «здесь старше профиль». Запись не исчезла — модель
  по-прежнему знает, что человек русскоязычный, но ведёт занятие по-французски.

## 6. Чем закончить

Профиль — это процедурная память: не «что я знаю о человеке», а «как я обязан работать».
У образцов она тоже отдельная — стиль ответа в Claude Code живёт своим файлом, а не в памяти.
