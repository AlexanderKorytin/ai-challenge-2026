# День 13. Состояние задачи — конечный автомат

**Стадия: Validation.** Пройдены `Research` → `Plan` → `Executing`.

## Условие

Реализовать состояние задачи как конечный автомат: этап задачи, текущий шаг, ожидаемое действие.
Пример состояний: `planning → execution → validation → done`. Проверить паузу на любом этапе и
продолжение без повторных объяснений.

## Видение пользователя

Профиль, заведённый командой `/profile new`, ведёт любую задачу по стадиям нашего конвейера:
`RESEARCH` (разбор и замысел — ведущий созывает консилиум, выбирает лучшее и выносит на
утверждение) → `PLAN` (план на утверждение) → `EXECUTING` → `VALIDATION` → `REPORT` → `DONE`,
с переходами как у нас. На видео — **сценарист**, экранизирующий роман Гарри Гаррисона
«Стальная крыса»; консилиум — профили «режиссёр», «продюсер», «знаток-романа».

## Что сделано

Дизайн — `docs/автомат-задачи.md` в ветке `main`, план — `docs/план-автомат-задачи.md` там же,
новая способность — `openspec/specs/task-machine/`. Код инструмента — в `main`.

- **Автомат — общее устройство.** Любой профиль с полем `stages` (карта: цель стадии,
  утверждение человеком, консилиум, переходы) ведёт задачу по стадиям. Карту заводит мастер
  `/profile new` из описания.
- **Модель двигает автомат вызовом инструментов DeepSeek:** `update_plan` (план стадии со
  статусами, текущий шаг, ожидаемое действие), `move_stage` (предложить переход),
  `call_council` (опросить консилиум стадии одновременно).
- **Программа проверяет переход по карте; ворота открывает только человек:** `/task утвердить`,
  `/task отклонить <замечание>`.
- **Пауза** — `/task пауза` / `/task продолжить`: на паузе инструменты с модели сняты.
- **Продолжение без объяснений:** стадия, цель, переходы, текущий шаг и ожидаемое действие
  уходят в каждый запрос из файла задачи — и после перезапуска тоже.
- **Экран:** у каждого круга «вызов → результат» свои свёрнутые размышления, вызовы видны
  строками, строка состояния показывает стадию и чей ход.

## Демонстрация

Из песочницы `test/`, с `MYHARNESS_PROFILES=~/.config/myharness/profiles` — чтобы мастер
положил «сценариста» в личный каталог, то есть сделал профиль глобальным. Профили консилиума
заведены заранее тем же мастером.
