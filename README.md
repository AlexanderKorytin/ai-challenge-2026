# AI SDLC Challenge 2026

Семинедельный челлендж: по одному заданию в будний день (5 в неделю → 35 заданий за 7 недель).
Челлендж стартовал **2026-08-31**.

Формат — AI SDLC: весь цикл разработки каждого задания (проектирование, код, тесты, деплой,
эксплуатация) ведёт Claude Code. Пользователь руками код не пишет и команды не запускает —
только там, где нужен доступ, которого нет у Claude (пароли, веб-консоли, разовые ручные шаги).

Правила и рабочий контекст челленджа — в [`CLAUDE.md`](./CLAUDE.md).

## Структура репозитория

```
week_<N>/              неделя, N = 1..7
  day_<M>/              задание дня, M = 1..5
    README.md            документация задания: постановка, решение, ход работы, ссылки на отчёт
    ...                  код и артефакты задания
```

Папки создаются по ходу челленджа — по одной на объявленное задание, не заранее.

## Видео-отчёты

По окончании задания дня (после подтверждения) записывается короткая демонстрация работы
кода и выкладывается на Google Диск, в общую папку:

📁 **Отчёты**: https://drive.google.com/drive/folders/1z12ya5LX-V0fsnBFgqpdqA52DLuydiu6

Ссылка на видео и на конкретный коммит с кодом дня добавляется в `README.md` соответствующей
папки `day_<M>`.

Команда для запуска отчёта: **`/отчет`** (локальный скилл, см. `.claude/skills/отчет/`).

## VPS

Серверная часть заданий поднимается на VPS (`ssh challenge`, см. `CLAUDE.md`). Код,
относящийся к серверным сервисам, дублируется/синхронизируется в `/opt/challenge/` на сервере —
детали конвенций там же, в `CLAUDE.md`.
