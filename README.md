# AI SDLC Challenge 2026

Семинедельный челлендж: по одному заданию в будний день (5 в неделю → 35 заданий за 7 недель).
Челлендж стартовал **2026-08-31**.

Формат — AI SDLC: весь цикл разработки каждого задания (проектирование, код, тесты, развёртывание,
эксплуатация) ведёт Claude Code. Пользователь руками код не пишет и команды не запускает —
только там, где нужен доступ, которого нет у Claude (пароли, веб-консоли, разовые ручные шаги).

Правила и рабочий контекст челленджа — в [`CLAUDE.md`](./CLAUDE.md).

## Задания

**Каждое задание живёт в своей ветке, а не в `main`.** В `main` остаётся общий инструмент
(`myharness`) и документация — то, что переживает день; задание, правящее инструмент под себя,
в `main` не сливается. На главной странице репозитория из папок дней видна только
`week_1/day_1` — историческое исключение; за остальными днями идти по ссылкам ниже, каждая
ведёт в ветку своего дня.

Действующее правило имени ветки дня — `w<номер недели>d<номер дня>` (`w2d1`, `w2d2`, `w2d3`).
Ветки первой недели — тоже исключение, сложившееся исторически: они названы по теме
(`day2-fish-facts`, `day3-logic`, `day4-temperature`, `day5-models`), переименованию не
подлежат, и ссылки в отчётах ведут на них.

## Структура репозитория

```
week_<N>/              неделя, N = 1..7
  day_<M>/              задание дня, M = 1..5
    README.md            документация задания: постановка, решение, ход работы, ссылки на отчёт
    ...                  код и артефакты задания
```

Папки создаются по ходу челленджа — по одной на объявленное задание, не заранее.

В корне ветки `main` лежат общий инструмент `myharness` (код и его проверки) и требования к
нему в `openspec/specs/` — источник правды о поведении инструмента. Ни то, ни другое не
принадлежит отдельному дню: ветка дня получает инструмент из `main`, а правки самого
инструмента делаются в `main` до создания ветки дня.

## Видео-отчёты

По окончании задания дня (после подтверждения) записывается короткая демонстрация работы
кода и выкладывается на Google Диск, в общую папку:

📁 **Отчёты**: https://drive.google.com/drive/folders/1z12ya5LX-V0fsnBFgqpdqA52DLuydiu6

Ссылок по итогам дня две, и ведут они в разные места.

- В `README.md` папки `day_<M>` ложатся ссылка на видео и ссылка на код дня, ведущая на **ветку
  дня**: фиксация не может содержать ссылку на саму себя, и снимок на конкретную фиксацию
  показывал бы состояние на шаг раньше — без ссылок и выводов.
- В чат пользователю уходит **постоянная ссылка на последнюю фиксацию** ветки дня: в ней ссылки
  на видео и код уже проставлены, поэтому снимок отдаёт полное состояние дня, и дальнейшие
  правки его не сдвинут.

Команда для запуска отчёта: **`/отчет`** (локальный навык, см. `.claude/skills/отчет/`).

## VPS

Серверная часть заданий поднимается на VPS (`ssh challenge`, см. `CLAUDE.md`). Код,
относящийся к серверным сервисам, дублируется/синхронизируется в `/opt/challenge/` на сервере —
детали конвенций там же, в `CLAUDE.md`.
