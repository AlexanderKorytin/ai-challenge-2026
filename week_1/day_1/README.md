# День 1 (2026-08-31)

## Статус

`Validation`

## Задание

Написать минимальный код, который отправляет запрос в LLM через API, получает ответ и
выводит его пользователю (CLI/Web). Провайдер — **DeepSeek API** (экономия).

Развёрнутая формулировка (получена в ходе постановки задачи): собрать минимальный
терминальный **harness** — `myharness`:

- запускается командой `myharness` в терминале, при старте — компактная минималистичная
  шапка (модель, статус авторизации, подсказка по командам);
- `/auth` — авторизация по API-ключу DeepSeek; проходит **один раз**, ключ запоминается
  между запусками (не вводить каждую сессию заново);
- `/model` — выбор модели (список + переключение);
- обычный текст — отправляется в DeepSeek, ответ стримится в консоль;
- если ответа ждём, а пользователь ввёл новый запрос — он встаёт в **очередь** и уходит в
  LLM сразу после того, как показан ответ на предыдущий;
- `Ctrl+C` во время ожидания ответа — отмена текущего запроса (не выход из harness);
- пока модель отвечает — анимированный индикатор «думает»; если модель поддерживает режим
  рассуждений (`reasoning_content`, DeepSeek thinking mode) — рассуждения тоже показываются
  пользователю по мере поступления;
- (дополнение по ходу работы) если пользователь отправляет запрос без авторизации —
  показать подсказку `/auth`, запрос не отправлять;
- (дополнение по ходу работы) любая ошибка при обращении к API (сеть, лимиты, невалидный
  ответ и т.п.) — показывается пользователю текстом, а не роняет harness.

## Ход работы

### Research

Изучена актуальная документация DeepSeek API (`api-docs.deepseek.com`):

- базовый URL `https://api.deepseek.com`, OpenAI-совместимый формат;
- авторизация — заголовок `Authorization: Bearer <ключ>`;
- модели: `deepseek-v4-flash` (дешёвая, без рассуждений по умолчанию — выбрана моделью
  по умолчанию ради экономии), `deepseek-v4-pro` (поддерживает thinking mode),
  `deepseek-v4-flash-vision-exp`;
- `GET /models` — список моделей и одновременно способ проверить валидность ключа;
- потоковый ответ (SSE): поле `delta.content` — обычный текст, `delta.reasoning_content` —
  текст размышлений (только у `-pro` с включённым `thinking`).

Инструменты: пакет `openai` (клиент с указанием `base_url`, сам разбирает SSE и отдаёт
`reasoning_content` как есть) вместо ручного парсинга потока; `prompt_toolkit` — асинхронный
ввод с очередью (пользователь печатает, пока стримится предыдущий ответ) и корректная
обработка `Ctrl+C` именно как отмена, а не падение процесса; `rich` — оформление
(шапка/спиннер/цвет), с осторожностью — стриминг текста модели идёт с `markup=False`,
чтобы `[` / `]` в ответе LLM не ломали разметку rich.

### Plan

Модули пакета `myharness` (`src/myharness/`):

| Модуль | Ответственность |
|---|---|
| `config.py` | Хранение ключа и модели по умолчанию в `~/.config/myharness/config.json` (`chmod 600`), **вне** репозитория и вне `.env` проекта — однократная авторизация между запусками |
| `api.py` | `DeepSeekClient` — обёртка над `AsyncOpenAI` с `base_url=https://api.deepseek.com`: `validate()` (проверка ключа), `list_models()`, `stream_chat()` (асинхронный генератор `StreamEvent(kind, text)`, `kind ∈ {reasoning, content}`) |
| `ui.py` | Шапка (`rich.Panel`), подсказки/ошибки/индикация очереди |
| `cli.py` | REPL: `PromptSession.prompt_async` + `patch_stdout` (вывод стрима не ломает строку ввода), `asyncio.Queue` — очередь сообщений, отдельная `asyncio.Task` на каждый запрос — для точечной отмены по `Ctrl+C`, анимированный спиннер (`\r` + braille-кадры) до первого токена |

### Executing

Собран `uv`-проект (`pyproject.toml`, entry point `myharness = "myharness:main"`),
реализованы все 4 модуля. Установлен как инструмент: `uv tool install --editable .`
— команда `myharness` доступна в терминале Mac без активации venv.

Учтены оба дополнения, поступившие по ходу работы:
- проверка авторизации **до** постановки сообщения в очередь (`cli.py:repl`) — иначе
  подсказка `/auth`;
- любая ошибка стрима (сеть, API) ловится в `generate_response()`, печатается через
  `ui.error(...)`, harness не падает и остаётся готов принимать следующий ввод; сообщение
  пользователя, оставшееся без ответа, откатывается из истории диалога (чтобы не ломать
  контекст следующего запроса).

### Validation

Автоматически проверено (не требует реального ключа DeepSeek):

- `uv sync` — зависимости ставятся, сборка пакета проходит;
- импорт всех модулей и `py_compile` — без ошибок;
- `config.py` — round-trip сохранения/чтения ключа, права файла `600` подтверждены;
- `ui.banner()` и прочие хелперы — рендер без исключений;
- сценарии `generate_response`/`worker` на **поддельном** клиенте (без сети):
  1. обычный ответ с рассуждениями — стрим отображается, история пополняется корректно;
  2. ошибка сети во время ответа — показывается пользователю, harness не падает, история
     не засоряется недоответом;
  3. отмена запроса (эмуляция `Ctrl+C`, `task.cancel()`) — вывод «запрос отменён»,
     harness остаётся в рабочем состоянии;
  4. два сообщения подряд, пока идёт ответ — оба уходят по очереди, история пополняется
     двумя парами `user`/`assistant`;
- реальный запуск `myharness` (неинтерактивный ввод/EOF) — шапка отрисовывается, выход
  происходит чисто, без трассировок исключений; проверено также прохождение подсказки
  `/auth` на неавторизованном вводе через полный REPL.

**Что не проверено автоматически** (нужен реальный ключ и настоящий терминал — сделать это
вручную умеет только пользователь, доступа к живому TTY и к ключу DeepSeek у меня нет):
живой ответ от DeepSeek, анимация спиннера и вывод рассуждений `-pro`-модели глазами,
поведение `Ctrl+C` при реальном нажатии, отсутствие визуальных артефактов интерфейса.

## Результат

Рабочий каталог: `week_1/day_1/` (пакет `myharness`, `src/myharness/{__init__,config,api,ui,cli}.py`).

**Быстрый старт:**

```bash
cd "week_1/day_1"
uv sync
uv tool install --editable .    # один раз — команда myharness появляется в PATH
myharness
```

**В самом harness:**

```
/auth              — ввести API-ключ DeepSeek (ввод скрыт, сохраняется на диск)
/model             — список моделей / /model <имя> — переключить
<текст>            — отправить сообщение в DeepSeek
Ctrl+C             — отменить текущий запрос
/help  /clear  /exit
```

Пользователю нужно вручную сделать только одно — ввести свой API-ключ DeepSeek через
`/auth` при первом запуске (это секрет, доступа к которому у Claude нет). Дальше harness
работает автономно.
