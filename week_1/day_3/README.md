## Задание

Взять одну задачу (логическую, алгоритмическую или аналитическую) и решить её через API
четырьмя способами:

1. прямой ответ без дополнительных инструкций;
2. с инструкцией «решай пошагово»;
3. модель сначала составляет промпт для решения задачи, затем этим промптом задача решается;
4. в промпте заведена группа экспертов (например аналитик, инженер, критик), решение
   получается от каждого.

Сравнить: отличаются ли ответы и какой способ дал наиболее точный результат.

Результат — несколько решений одной задачи и их сравнение.
