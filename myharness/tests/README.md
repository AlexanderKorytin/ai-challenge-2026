# Проверки harness

Запускаются без ключа DeepSeek и без настоящего терминала: вместо API — поддельный клиент,
вместо терминала — труба и пустой вывод prompt_toolkit. Настройки и профили на время
проверок подменяются временным каталогом (`MYHARNESS_CONFIG_DIR`, `MYHARNESS_STATE_DIR`, `MYHARNESS_PROFILES`) —
без этого они писали бы в настоящий `~/.config/myharness/config.json` и затирали ключ.

```bash
cd myharness
uv run python tests/check_units.py   # профили, журнал, параметры, панель, дополнения
uv run python tests/check_app.py     # приложение целиком: клавиши, панели, ответ, журнал
uv run python tests/check_layers.py  # слои памяти через настоящую точку входа cli.repl
```

`check_layers.py` отличается от двух других тем, что НЕ собирает состояние руками: он поднимает
`cli.repl` и шлёт нажатия трубой. Разница не косметическая — проверка, собирающая состояние
сама, по построению не видит бед вида «нужное просто не заводится при запуске».
