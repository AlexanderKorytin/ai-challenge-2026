# /задание — конвейер дня

Один вызов на задание дня. Ведёт от условия и видения пользователя до двух ссылок в чате.
Стадии и разрешённые переходы — из `CLAUDE.md`, этот навык их не заменяет, а наполняет
процедурами.

Язык всей работы — русский, транслитерация английских слов запрещена.

```
условие + видение
   │
   ▼ Research     /штурм       разбор → профильные агенты параллельно → подходы → дизайн → «да»
   ▼ Plan         /план        шаги 2–5 минут, без заглушек, самопроверка на покрытие
   ▼ Executing    /исполнение  исполнитель + отдельный проверяющий на каждый шаг
   ▼ Validation   /проверка    прогон, сверка с openspec, просмотр ветки, честный список пропусков
   ▼ Report       /отчет       запись экрана, Google Диск, GitHub
   ▼ Done         две ссылки пользователю
```

## Перед первой стадией

1. **Завести папку дня** — `week_<N>/day_<M>/`, но **только если пользователь этого просил**
   (правило `CLAUDE.md`). Перед созданием проверить, что папки нет, чтобы не затереть работу.
2. **Завести ветку дня** — `day<N>-<тема>`. Задание, правящее поведение инструмента под себя,
   в `main` не сливается; исправления самого инструмента делаются в `main` и подтягиваются
   в ветку дня слиянием.
3. **Прочитать требования** затронутых способностей в `openspec/specs/` — это источник правды
   по действующему поведению `myharness`, а не раздел `CLAUDE.md`.
4. **Завести `week_<N>/day_<M>/README.md`** с постановкой задания. Дальше он пополняется по
   стадиям и в конце принимает ссылки.

## Правила, действующие на всех стадиях

- **Стадию называть вслух** при каждой смене: «`Research → Plan`». Неразрешённых переходов нет.
- **Статусы обновлять самому**, без напоминаний: стадия в `README.md` дня и строка в таблице
  заданий `CLAUDE.md`.
- **Право не соглашаться.** Видение пользователя ведёт к костылю, дыре в безопасности или
  техдолгу — возразить и предложить альтернативу. Настаивает — риски назвать и записать в отчёт.
- **Качество выше скорости.** «Потом поправим» и «сойдёт для прототипа» не принимаются.
- **Пользователь ничего не делает руками.** Весь код, запуск, отладка, git — на Claude.
  Пользователю задача ставится только там, где нужен недоступный доступ: пароль, веб-консоль
  провайдера, секрет, разрешение macOS.
- **Попутно объяснять.** Пользователя учат с нуля: новые понятия разжёвывать, полезны параллели
  с миром Kotlin и JVM.
- **Живые прогоны — из песочницы** `week_<N>/day_<M>/test/`, не из корня папки дня.

## Если задание не про инструмент

Конвейер тот же. Меняются только затрагиваемые требования: их может не быть вовсе — тогда
`openspec` не трогаем, а дизайн и план живут в папке дня как обычно.
