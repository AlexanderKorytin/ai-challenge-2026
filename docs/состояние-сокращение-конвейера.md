## Устные решения по ходу, не входившие в дизайн

- **Напоминание об отложенных задачах отменено** по прямой команде пользователя: «не тяни каждый
  запуск — лучше буду спрашивать сам». Прежнее правило требовало обратного. Память обновлена,
  `CLAUDE.md` тоже. Дизайн этого не покрывал — решение принято после его утверждения.
- **Разделение `cli.py` назначено на 2026-09-13** первой работой по новому конвейеру, общей
  задачей в `main`, без ветки и папки дня.
- **Мера цели** задана пользователем: день уровня дня 9 за миллион токенов. Обещано честно:
  1–1,5 млн для знакомой задачи, 2–4 млн для дня с исследованием; паритет с 500 тысячами
  недостижим при сохранении независимого просмотра.
- **Чтение большой базы дешёвой моделью** (1–3 помощника, выжимка с адресами — одному `opus`)
  внесено в `/исполнение` по предложению пользователя, сверх исходного объёма задачи.

## Отвергнутое внутри шагов

- Разбиение `check_units.py` под pytest и связь требований с проверками — **не рычаг экономии**:
  в записях нет ни одного чтения файла целиком, читали диапазонами. Вынесено отдельной задачей
  после `cli.py`.

  правилу «никаких своих ограничений»: вместо них признаки и расчётные пороги.
