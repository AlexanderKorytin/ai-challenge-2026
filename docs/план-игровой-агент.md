# План: игровой агент (день 35)

Дизайн: `docs/игровой-агент.md`, утверждён 2026-10-16. Состояние: `docs/состояние-игровой-агент.md`.

## Изменения требований

Требований `myharness` задача не задевает: код `myharness` не меняется, приложение пользуется им
как библиотекой (`Agent`, `profiles`, `memory`, `project_card`, `invariants`, `api`,
`mcp_tools`, `journal`). Новых способностей в `openspec/specs/` нет: это приложение, а не
поведение инструмента — так же, как `agents/digest` и `agents/review`.

Одно место сверки для стадии `Spec`: приложение пишет строку в раздел «Ограничения» карточки
папки с источником «человек» по нажатию кнопки «минус». Требование `memory` → «Раздел
«Ограничения» карточки пишет только человек» требует, чтобы адрес записи назвал человек. Здесь
адрес называет кнопка, которую нажал человек; модель в записи не участвует.

## Уточнение дизайна

Дизайн говорит «модель пишет разделы карточки естественной записью». Естественная запись
`myharness` срабатывает на зачин в реплике человека и живёт в главном экране терминала, а `Agent`
сам её не делает. Поэтому модель пишет вкус инструментом `save_taste`: он зовёт
`project_card.create(каталог, разделы, источник="модель")`. Тот же замок `create` сохраняет
«Ограничения» человека и отбрасывает их из ответа модели. Канал записи один — карточка.

## Договоры модулей

### `steam_store`

**Владеет**: ничем; состояния нет.
**Отдаёт**:

```python
@dataclass(frozen=True)
class Метка: номер: int; имя: str
@dataclass(frozen=True)
class Отзывы: сводка: str; положительных: int; всего: int   # всего == 0 → «отзывов нет»
@dataclass(frozen=True)
class Игра:
    номер: int; имя: str; описание: str; жанры: tuple[str, ...]
    дата_текст: str; дата: date | None; вышла: bool
    цена: int | None; цена_без_скидки: int | None; скидка: int; валюта: str  # цена в копейках
    отзывы: Отзывы; ссылка: str

class ОшибкаМагазина(Exception): ...

async def метки(клиент) -> list[Метка]                      # tagdata/populartags/russian
async def найти(клиент, метка: int, *, будущие: bool) -> list[int]   # search/results, одна страница
async def игра(клиент, номер: int) -> Игра | None           # appdetails + appreviews; None — магазин не знает
def разобрать_дату(текст: str) -> date | None               # «3 Aug, 2023», «3 авг. 2023»; «Q1 2027» → None
```

**Обещает**: регион `cc=ru`, язык `l=russian`. Ответ 429 или 5xx — три повтора с паузой 2, 4,
8 с, затем `ОшибкаМагазина`. Номера поиска без повторов, в порядке выдачи.
**Не делает**: не пишет на диск, не знает SQLite.

### `games_db`

**Владеет**: файлом `games.sqlite`. Читают и пишут три процесса: сервер MCP (только чтение),
задания, веб. Режим `WAL`, `busy_timeout` 5000 мс.
**Отдаёт**:

```python
def путь() -> Path                                   # $GAMES_DATA_DIR/games.sqlite
def открыть(только_чтение: bool = False) -> sqlite3.Connection   # схема создаётся при первом открытии
def запомнить_игру(с, игра: Игра) -> None            # таблица games, по номеру
def предложить(с, номер: int, причина: str) -> bool  # suggestions; False — уже предлагалась
def оценить(с, номер: int, плюс: bool, причина: str) -> None
def в_календарь(с, номер: int, причина: str) -> bool # calendar; False — уже стоит
def желаемое(с) -> list[dict]
def показанные(с) -> set[int]                        # предложения ∪ календарь: повторно не судить
def отметить_цену(с, номер: int, цена: int, скидка: int) -> bool   # True — новая скидка
def в_ленту(с, род: str, текст: str) -> None         # род: скидка | сбой | итог
def лента(с, сколько: int | None = None) -> list[dict]
```

**Обещает**: запрос по номеру, а не по имени. `отметить_цену` возвращает `True` один раз на пару
«игра, цена со скидкой»: та же скидка второй раз не сообщается, новая цена — сообщается.
**Не делает**: сети не знает, карточку `myharness` не читает.

### `taste`

**Отдаёт**:

```python
РАЗДЕЛЫ = ("Любимые игры", "Общее", "Критерии", "Нежелательное")
@dataclass(frozen=True)
class Критерий: метка: int; имя: str; вес: int
def критерии(каталог: Path) -> tuple[list[Критерий], list[str]]   # жалобы — строки не того вида
def запреты(каталог: Path) -> set[int]                            # номера из «Ограничений»
def опрос_пройден(каталог: Path) -> bool                          # есть «Критерии»
def запретить(каталог: Path, игра: Игра) -> tuple[bool, str]      # add_line, источник «человек»
def снять_запрет(каталог: Path, номер: int) -> tuple[bool, str]   # remove_line, источник «человек»
def набор(каталог: Path, метки: list[Метка]) -> Инструменты       # инструмент save_taste
```

Вид строки «Критериев»: `<имя> (<номер>) — <вес>`, вес — целое от 1 до 5. Вид строки запрета:
`Не предлагать: <имя> (<номер>)`.
**Обещает**: `save_taste` отвергает номер метки не из списка магазина и возвращает модели текст
отказа с плохими строками. Нечего писать — карточка не трогается.
