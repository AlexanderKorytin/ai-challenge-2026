## Видение пользователя (2026-10-16)

- DeepSeek опрашивает человека о любимых играх, находит общее и формирует критерии вкуса.
- Местная модель раз в неделю смотрит новые выпуски Steam по критериям и отмечает их в календаре.
- Каждый день агент ищет вышедшие игры Steam и предлагает добавить их в список желаемых.
- При скидке на игру из списка желаемых агент уведомляет человека.
- Веб-интерфейс. Каждое предложение человек оценивает.
- Плюс — игра в список желаемых и под наблюдение скидок.
- Минус — игра в запреты (инварианты), DeepSeek пересматривает приоритеты.

## Факты разведки

- Магазин Steam отвечает с Мака без ключа: `api/appdetails` (цена, скидка, жанры, дата),
  `api/featuredcategories` (`coming_soon`, `new_releases`, `specials`),
  `search/results?json=1`.
- Настоящий список желаемых Steam открытым API не пишется: нужен вход в учётную запись.
