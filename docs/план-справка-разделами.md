# План: справка разделами (отложенная задача 13)

Вход — утверждённый дизайн `docs/справка-разделами.md`. Состояние работы —
`docs/состояние-справка-разделами.md`.

Обмена с моделью задача не трогает: живого прогона с моделью нет, проверка — поднятое
приложение в `check_app`/`check_layers` и ручной сценарий в терминале.

## Договор модуля `helpdoc`

Читатели за границей файла: `commands.py`, `commands_model.py`, `layout.py`, обе проверки.

**Владеет**: ничем изменяемым. Состояния не держит, на диск не ходит.

**Отдаёт**:

```python
ШИРИНА_АБЗАЦА_СПРАВКИ: int = 84             # переезжает из ui без изменения смысла

@dataclass(frozen=True)
class Раздел:
    слово: str        # то, что набирают: «память»; строчные, без пробелов, уникально
    заголовок: str    # то, что показывают: «Память»
    подсказка: str    # правый столбец меню, о чём раздел
    текст: Callable[[], str]   # полный текст раздела без заголовка; вызывается при показе,
                               # потому что таблица команд и список зачинов живые

РАЗДЕЛЫ: tuple[Раздел, ...]                 # порядок меню, десять штук, порядок из дизайна

def найти(слово: str) -> list[Раздел]       # без учёта регистра и крайних пробелов; точное
                                             # слово — один раздел; иначе все разделы, чьё
                                             # слово начинается с набранного (0, 1 или больше)
def фрагменты(раздел: Раздел) -> Fragments   # строка заголовка «Справка · <заголовок>» классом
                                             # class:system, затем текст, затем строка
                                             # «/help — все разделы» классом class:dim
def ошибка(слово: str, подходящие: list[Раздел]) -> Fragments
                                             # ui.error_fragments: пусто — «нет раздела справки
                                             # «X»; разделы: <все слова>»; больше одного —
                                             # ««X» подходит к нескольким: <их слова>»
def _строка_зачинов() -> str                 # переезжает из ui без изменения
```

**Обещает**: слова разделов уникальны и ни одно не является началом другого — иначе `найти`
по полному слову давал бы неоднозначность (проверяется в `check_app`). Пустое слово даёт пустой список (команда его не передаёт: пустой довод открывает меню).
Ни одна строка текста не теряется при переносе: объединение текстов всех разделов содержит
каждую непустую строку нынешней справки, кроме заголовков, ставших заголовками разделов.

**Не делает**: панели не открывает и в ленту не пишет — это делает `commands`. `ui` не ввозит
`helpdoc` (иначе круг `ui → helpdoc → recognizer → … → ui`); `helpdoc` ввозит `ui` и
`recognizer` наверху.

## Изменения требований

- `commands` → «Состав команд»: сценарий «справка» заменяется четырьмя: `/help` (и `/help` с одними
  пробелами) открывает меню разделов справки — Enter или щелчок печатает раздел в ленту, Esc
  закрывает без печати; `/help <слово>` печатает раздел справки сразу, начало слова принимается;
  начало, подходящее к нескольким разделам справки (`/help к` — `команды` и `карточка`), даёт
  ошибку с перечнем подходящих слов, ничего не печатает и меню не открывает; незнакомое слово —
  ошибка с перечнем всех слов, меню не открывается. Абзацем — перечень десяти разделов справки
  (слово и заголовок). В новом тексте везде «раздел справки» и форма `/help <слово>`: голое
  «раздел» в `commands` и `memory` уже значит раздел карточки и рабочей памяти.
- `commands` → «Команды памяти подсказывают следующим уровнем»: дописать, что после «/help »
  подсказываются слова разделов справки — целыми словами, а команда принимает и их начало.
- `commands` → «У каждого слоя памяти есть запись, чтение и удаление»: «узнать из `/help`» →
  «из раздела справки «Память»»; «справка SHALL показывать эти команды таблицей» → «раздел
  справки «Память» SHALL показывать…»; сценарий — `/help память`.
- `commands` → «Команды стратегий доступны в меню и справке»: «описаны в `/help`» → «в разделе
  «Команды» справки»; сценарий — `/help команды`.
- `commands` → требование `/invariants` («стоять в меню команд и в справке»): уточнить «в разделе
  «Команды» и в разделе «Инварианты»».
- `interface` → требование про клавишу обхода: «справка SHALL называть» → «раздел «Мышь и клавиши»
  справки SHALL называть»; сценарий — `/help мышь`.
- `memory` → «Естественная запись в слои памяти», сценарий «справка называет зачины»: «человек
  смотрит `/help`» → «человек открывает раздел «Карточка и естественная запись» справки
  (`/help карточка`)». Требование «справка SHALL печатать его оттуда же» не меняется.
- `invariants` справку не упоминает.

## Шаг 1. Справка разложена по разделам: меню `/help`, `/help <слово>`, подстановка слов

**Файлы**: `helpdoc.py` (новый), `ui.py`, `commands.py`, `commands_model.py`, `layout.py`,
`tests/check_app.py`, `tests/check_layers.py`
**Зависит от**: ничего
**Ход**: быстрый — все читатели `helpdoc` в файлах этого же шага, панель выбора существующая.
**Требование**: `commands` → «Состав команд», «Команды памяти подсказывают следующим уровнем»,
«У каждого слоя памяти…», «Команды стратегий…», `/invariants`; `interface` → клавиша обхода.
**Проверка**: `check_app` и `check_layers` зелёные; в них:
- `/help мышь` печатает «обхода перехвата» и «решает терминал», а `/help команды` — нет
  (парная проверка соседнего значения);
- `/help карточка` печатает все зачины и абзац зачинов; `/help ПАМ` печатает таблицу слоёв;
- `/help нет-такого` печатает ошибку с перечнем слов, панель не открыта;
- `/help к` печатает ошибку с `команды` и `карточка` и без `память`, а `/help ко` печатает
  раздел «Команды»; `/help ` (пробел) открывает панель;
- слова разделов уникальны и не начинают друг друга;
- ключевые фразы прежней справки (по одной на абзац, списком в проверке) нашлись каждая ровно
  в одном разделе;
- `/help` Enter → панель открыта, строк десять, заголовок «/help — справка»; ↓ и Enter → в ленте
  «Справка · Память», панель закрыта; снова `/help`, Esc → панель закрыта, лента не выросла;
- набор «/help ин» → среди подстановок `инварианты`, и нет `память` (парная).

Ручной сценарий в терминале: `/help`, щелчок по строке «Мышь и клавиши» печатает раздел.
**Содержание**:
- `helpdoc.py` по договору. Тексты разделов — нынешние абзацы из `ui.help_fragments` по таблице
  дизайна, дословно; связки правятся только там, где абзац ссылался на соседа, которого в разделе
  больше нет. Таблица команд строится из `ui.COMMANDS` так же, как сейчас, внутри раздела
  «Команды».
- Подсказки меню: команды — «все команды и меню по «/»»; память — «четыре слоя: что, куда, чем
  убрать»; инварианты — «правила, которые модель не нарушает»; автомат — «стадии, ворота, пауза»;
  карточка — «знание о папке и запись обычными словами»; профиль — «/profile new разговором»;
  группа — «агенты, экраны, способы»; сжатие — «выжимка, /context, /compact»; токены — «/tokens и
  /budget»; мышь — «клики, выделение, прокрутка, горячие клавиши».
- `ui.COMMANDS`: `("/help", "[слово]", "справка по разделам: команды, память, клавиши…", False)`.
- `commands_model.open_help_picker(state)`: `Item(label=р.заголовок, hint=р.подсказка,
  payload=р)` по `helpdoc.РАЗДЕЛЫ`; `choose` → `state.picker = None`, `append_log(state,
  helpdoc.фрагменты(payload))`; `Picker(title="/help — справка", description="какой раздел
  показать", marked=None)`; `refresh(state)`.
- `commands.handle_command`: `/help` без довода → `commands_model.open_help_picker(state)`;
  с доводом → `подходящие = helpdoc.найти(arg)`: ровно один — `append_log(state,
  helpdoc.фрагменты(подходящие[0]))`, иначе — `append_log(state, helpdoc.ошибка(arg, подходящие))`.
- `layout.CommandCompleter`: ветка `command == "/help" and len(parts) == 2` — по `РАЗДЕЛЫ`,
  `Completion(р.слово, display=р.слово, display_meta=р.заголовок)` для слов, начинающихся с
  набранного без учёта регистра.
- Проверки: четыре места `check_app` переводятся на текст своего раздела
  (`helpdoc.фрагменты(helpdoc.найти(…)[0])`); `check_layers` шлёт `/help карточка` и берёт
  `ШИРИНА_АБЗАЦА_СПРАВКИ`, `_строка_зачинов` из `helpdoc`.
