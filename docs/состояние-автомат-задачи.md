## Итоги шага 1 — живой замер DeepSeek (`deepseek-v4-flash`, рассуждения включены), 2026-09-16

- Имя инструмента — только `^[a-zA-Z0-9_-]+$`: русское имя даёт 400. Инструменты называются
  `update_plan`, `move_stage`, `call_council`. Русские имена ДОВОДОВ сервер принимает.
- Вызов: `finish_reason = tool_calls`, `content` пустой; первый кусок несёт `id`, `type`,
  `function.name` и пустые доводы, дальше доводы идут кусками по `index`.
- Продолжение после результата инструмента пришло без рассуждений (0 знаков) — пустые
  рассуждения круга законны.
- Сервер НЕ отказывает: старая пара без `reasoning_content` при `tools`; пустая строка;
  прошлый ход с вызовом без рассуждений; запрос без `tools`, в истории которого вызов.
  Решение для `раскрыть(полные=True)`: рассуждения кладутся, когда они записаны; у пары без
  них ключ не ставится. Пауза (снятие `tools`) не ломает разговор.
- Шум `generator didn't stop after athrow()` — известный дефект httpcore2, в `api.aclose`
  уже обойдён; к делу не относится.
- Отступ от плана: ключ карты в json профиля — `stages` (поля `name`, `goal`, `approval`,
  `council`, `next`), как все ключи json профиля; имена в Python русские.
