# План: сокращение расхода конвейера

Основание — `docs/сокращение-конвейера.md`, утверждён пользователем 2026-09-12.
Общая задача в `main`. Все шаги быстрого хода: изменения текстовые, чужого читателя за границей
файлов шага нет. Независимый просмотр — один, по связному шву, после шага 7.

## Шаг 1. Измеритель расхода
**Файлы**: `bin/расход.py`
**Зависит от**: ничего
**Проверка**: запуск за 2026-09-10 даёт 315,6 млн входа и 1396 обменов (536 ведущего, 860
помощников), за 2026-09-11 — 213,8 млн и 2157 обменов; помощники считаются отдельной строкой.
Числа сложены по обеим средам: Claude Code и OMP.
**Содержание**: чтение `~/.claude/projects/<копия>/*.jsonl` и `<сеанс>/subagents/*.jsonl` по
уникальным `requestId` плюс `~/.omp/stats.db` с отбором по папке; дни по местному времени; ключи
`--день`, `--с`, `--по`, повторяемый `--копия`, по умолчанию все рабочие копии `~/challenge`;
вывод по дням: обменов ведущего и помощников, вход, выход, деньги. Только чтение, ничего не пишет.

## Шаг 2. `/исполнение` — помощник, ход, порчи, модели
**Файлы**: `.claude/skills/исполнение/SKILL.md`
**Зависит от**: ничего
**Проверка**: в тексте нет долгого разговора с помощником вне круга снятия замечаний; признак
полного хода — «чужой читатель за границей файлов шага» с двумя исключениями; порча оставлена
только для порядка и чередования.
**Содержание**: одноразовое поручение; признак хода с обязательной причиной; парные проверки и
утверждение предусловия вместо порчи; дешёвая модель на механику, `Explore` на разведку;
крупные ходы — независимые команды одним обменом, файл целиком вместо череды правок.

## Шаг 3. `/план` — причина хода, живой прогон, самопроверка
**Файлы**: `.claude/skills/план/SKILL.md`
**Зависит от**: шаг 2 (имена признаков совпадают)

**Содержание**: поле «Ход» с причиной; условие на графе зависимостей — шаг с живым обменом не
зависит от шагов интерфейса; убрать обязательность договоров для всех модулей подряд.

## Шаг 4. `/проверка` — один проход, просмотр по швам

## Шаг 5. `/штурм` — профильный разбор по признаку, артефакты файлами

## Шаг 7. `CLAUDE.md` — разгрузка пола

## Шов и проверка
Один независимый просмотр всего изменения помощником: связность навыков между собой, совпадение
имён признаков, отсутствие противоречий с `CLAUDE.md`. Затем ведущий запускает измеритель и
сверяет числа шага 1.

## Самопроверка
- Каждый рычаг дизайна закрыт шагом: помощник — 2, ходы и рубежи — 2 и 6, пол — 7, модели — 2,
  разведка — 2, измеритель — 1.
- Ни один шаг не повторяет работу стадии `Validation`.
- Живой прогон здесь неприменим: задача не трогает обмен с моделью, и это сказано прямо.
- Имена признаков («чужой читатель за границей файлов шага», «парная проверка», «рубеж») едины
  для шагов 2–6.
